# Python para Análise e Automação de Dados
 
## Sobre o Projeto
 
Este projeto foi desenvolvido utilizando NotebookLM para criar um ambiente de aprendizagem sobre Python, análise de dados e automação.
 
## Objetivo
 
Construir um segundo cérebro utilizando IA generativa e fontes confiáveis para apoiar o estudo de Python aplicado à análise e automação de dados.

## Tecnologias Estudadas
 
- Python
- Pandas
- OpenPyXL
- Excel
- Automação de Dados
 
## Evidências Produzidas
 
Foram realizadas perguntas para validar o conhecimento construído pelo NotebookLM:
 
1. Integração entre Python, Pandas e OpenPyXL
2. Fundamentos de Python
3. DataFrames no Pandas
4. Qualidade de Dados
5. Automação de Relatórios
6. Projeto Integrado
